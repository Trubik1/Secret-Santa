# Telegram Mini App «Wishlist» 🎁

> Эстетичный сервис списков желаний для Telegram с нулевой стоимостью инфраструктуры на базе **Telegram Serverless (`tgcloud`)**, **SQLite** и **React (Vite + Tailwind CSS)**.

---

## ✨ Возможности

- **Эстетика Unibb:** Пастельные тона (`#c4457b`, `#f8eff3`), шрифт `Manrope`, Bento-сетка, карточки со скруглением 28px, pill-кнопки.
- **Поддержка тем:** Автоматическая адаптация под светлую и тёмную тему клиента Telegram.
- **Режим «Сюрприз»:** Создатель вишлиста не видит, какие именно подарки забронированы (видит только общий счётчик *«Забронировано 3 из 8»*), сохраняя интригу до дня рождения.
- **Бронирование в 1 клик:** Гости могут забронировать подарок, чтобы не дарить одинаковое.
- **Складчина («Скинуться»):** Для дорогих подарков друзья могут объединяться и вносить долю. Прямая координация переводов по `@username` участников без посредников и комиссий.
- **Авто-парсер ссылок:** Вставьте ссылку на Wildberries, Ozon или любой другой маркетплейс — парсер автоматически достанет фото, заголовок и цену с ручным редактированием при необходимости.
- **Telegram Bot интеграция:** Уведомления владельцу и гостям, запуск по прямой ссылке `t.me/<bot_username>?start=wish_<user_id>`.

## 🚀 Быстрый старт (Локальная разработка)

В проект встроен гибридный мок-слой: вы можете разрабатывать и тестировать в обычном браузере без запуска Telegram!

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера разработки
npm run dev
```

В браузере откроется приложение с панелью **Dev Bar** сверху:
- Переключатель режимов: **Владелец (Сюрприз)** / **Гость (Даритель)**
- Смена темной/светлой темы
- Сброс тестовых данных

## ☁️ Развертывание в Telegram Serverless (`tgcloud`)

Telegram Serverless выполняет бэкенд прямо в инфраструктуре Telegram (<5мс cold start, 0 ₽ расходов).

### 1. Получение CLI токена в @BotFather:
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте `/mybots` и выберите вашего бота (например, `@yamload_bot`).
3. Перейдите: **Bot Settings** → **Serverless** → **CLI Access** → **Generate Token** (формат токена: `app<id>:<secret>`).

### 2. Привязка и деплой:
```bash
# Авторизация в CLI
npx tgcloud login
# Вставьте полученный токен app...

# Применение схемы базы данных SQLite
npx tgcloud migrate

# Сборка фронтенда и публикация в Telegram Cloud
npm run deploy
```

После деплоя Mini App будет доступен по официальному URL `https://app<id>.tgcloud.ai/` и сразу подключен к боту!

│   ├── api/
│   │   ├── serverless.ts         # Гибридный клиент Telegram Serverless / Local Mock

│   ├── components/               # Bento UI компоненты

│   │   ├── CategoryFilter.tsx    # Фильтр категорий (pill кнопки)
│   │   ├── AddGiftModal.tsx      # Модалка добавления (парсер + поля)
│   │   ├── PledgeModal.tsx       # Модалка складчины с контактами соучастников
│   │   ├── EditProfileModal.tsx  # Настройка даты и названия события

│   │   └── DevToolsBar.tsx       # Панель переключения Владелец/Гость
│   ├── hooks/useTelegram.ts      # Хук Telegram WebApp SDK & Haptics
│   ├── types.ts                  # TypeScript модели данных
│   └── App.tsx                   # Корневое приложение
├── tgcloud/                      # Бэкенд Telegram Serverless
│   ├── schema.js                 # DDL SQLite (users, gifts, gift_pledges, categories)
