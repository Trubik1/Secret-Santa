# Полная спецификация и мастер-промпт: Telegram Mini App «Wishlist» (Вишлист)

> **Назначение документа:** Этот файл является исчерпывающим техническим заданием и готовым системным промптом для ИИ-агента (или разработчика). Скормив этот документ ИИ, он сможет автономно сгенерировать и развернуть полноценный Telegram Mini App без дополнительных вопросов.

---

## 1. Концепция и ключевая ценность
**Telegram Mini App «Wishlist»** — эстетичный, однопользовательский сервис списков желаний для Telegram с нулевой стоимостью инфраструктуры (0 ₽ на хостинг и сторонние API).

### Основные сценарии:
1. **Для создателя вишлиста (Владелец):** 
   - Заходит в Mini App через Telegram (авторизация по `initData` без логинов/паролей).
   - В один клик добавляет подарки: вставляет ссылку на Ozon, Wildberries или любой другой сайт (парсер вытягивает фото, название и цену) либо вводит вручную.
   - Указывает дату своего праздника/ДР и теги/категории.
   - Получает персональную ссылку вида `t.me/<bot_username>?start=wish_<user_id>` и размещает её в био профиля, сторис или отправляет друзьям.
2. **Для друзей и гостей (Дарители):**
   - Открывают вишлист по ссылке без обязательной регистрации.
   - Видят витрину подарков с фильтрами по категориям.
   - Могут в один клик **«Забронировать»** подарок (чтобы другие гости не подарили то же самое).
   - Для дорогих подарков — могут нажать **«Скинуться»** и указать сумму взноса. Приложение связывает скидывающихся через их Telegram `@username` для прямой координации переводов без посредников и комиссий.
3. **Режим «Сюрприз»:**
   - Гости видят актуальный статус: *«Свободен»*, *«Забронирован»*, *«Идет сбор: 4 000 / 12 000 ₽»*.
   - Создатель вишлиста в своем интерфейсе **НЕ видит**, какой именно подарок забронирован (видит лишь общий счетчик, например *«Забронировано 4 из 10 подарков»*), сохраняя интригу до самого праздника.

## 2. Архитектура и стек технологий

| Компонент | Технология | Обоснование |
|---|---|---|
| **Хостинг и Runtime** | **Telegram Serverless (`tgcloud`)** | Официальная инфраструктура Telegram. 0 ₽ расходов, мгновенный старт (<5мс), деплой через `npx tgcloud push`. |
| **База данных** | **Встроенный SQLite (tgcloud)** | Персистентная база, идущая из коробки с `tgcloud`, со встроенным Query Builder. Никаких внешних СУБД. |
| **Фронтенд** | **React 18 + Vite + TypeScript + Tailwind CSS** | Моментальный билд, легкий бандл, поддержка Telegram WebApp SDK (`@twa-dev/sdk`). |
| **Стилистика** | **Bento-сетка в духе `unibb.vercel.app`** | Чистый минимализм, шрифт `Manrope`, пастельные карточки, скругления `border-radius: 24-32px`, скругленные кнопки (pill). |
| **Темизация** | **Auto Theme (Light / Dark)** | Светлая эстетика unibb по умолчанию + адаптивная темная тема под настройки клиента Telegram. |
| **Парсинг ссылок** | **Автономный микро-парсер (Node.js)** | Извлечение OpenGraph мета-тегов (`og:image`, `og:title`, `og:price`) + регулярные парсеры для ссылок Wildberries и Ozon. Ручной ввод как безотказный фоллбэк. |
| **Уведомления** | **Telegram Bot API (Webhook/Handlers)** | Информирование создателя о бронировании (без раскрытия подарка), отправка дарителю напоминания и обмен `@username` участников складчины. |

### Принципы интерфейса:
1. **Типографика:** Шрифт `Manrope` (жирные акцентные заголовки `font-extrabold`, компактный трекинг `letter-spacing: -0.03em`).
2. **Формы компонентов:** 
   - Кнопки: форма pill (`rounded-full`, высота 50-54px, плавные микро-анимации нажатия).
   - Карточки товаров: крупные радиусы скругления (`rounded-3xl` / 28px), отсутствие резких черных рамок, мягкие заливки.
   - Фотографии: соотношение сторон 4:3 или 1:1, `object-cover`, легкий эффект скругления.
3. **Haptic Feedback:** При клике на кнопки «Забронировать», переключении табов и добавлении товара вызывается нативный `Telegram.WebApp.HapticFeedback.impactOccurred('medium')`.

## 4. Структура базы данных (SQLite в `tgcloud`)

```sql
-- Пользователи Telegram
CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY,            -- telegram user_id
    first_name TEXT NOT NULL,
    last_name TEXT,
    username TEXT,
    photo_url TEXT,
    event_title TEXT DEFAULT 'Мой День Рождения',
    event_date TEXT,                   -- YYYY-MM-DD
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Категории (теги)
CREATE TABLE IF NOT EXISTS categories (
    id TEXT PRIMARY KEY,               -- 'all', 'gadgets', 'clothes', 'home', 'books', 'other'
    title TEXT NOT NULL,
    icon TEXT NOT NULL
);

-- Подарки в вишлисте
CREATE TABLE IF NOT EXISTS gifts (
    id TEXT PRIMARY KEY,               -- UUID
    user_id INTEGER NOT NULL,          -- владелец подарка
    title TEXT NOT NULL,
    price INTEGER DEFAULT 0,           -- цена в рублях
    currency TEXT DEFAULT 'RUB',
    url TEXT,                          -- ссылка на магазин
    image_url TEXT,
    category_id TEXT DEFAULT 'other',
    priority INTEGER DEFAULT 1,        -- 1 (хочу), 2 (очень хочу), 3 (мечта)
    is_crowdfund BOOLEAN DEFAULT 0,    -- 1 = можно скинуться
    target_amount INTEGER DEFAULT 0,   -- целевая сумма сбора
    is_booked BOOLEAN DEFAULT 0,       -- 1 = забронирован целиком
    booked_by_user_id INTEGER,         -- кто забронировал
    booked_at DATETIME,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY(user_id) REFERENCES users(id)
);

-- Доли складчины (кто скинулся на дорогой подарок)
CREATE TABLE IF NOT EXISTS gift_pledges (
    id TEXT PRIMARY KEY,
    gift_id TEXT NOT NULL,
    user_id INTEGER NOT NULL,          -- кто скинулся
    user_name TEXT NOT NULL,
    user_username TEXT,                -- @username для связи
    amount INTEGER NOT NULL,           -- сумма доли
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY(gift_id) REFERENCES gifts(id)
);
```

## 5. Экраны и сценарии Mini App

### Экран 1: Витрина вишлиста (Главный экран)
- **Шапка (Hero-профиль):**
  - Аватар пользователя, имя и `@username`.
  - Заголовок события (например: *«День рождения Артема 🎂»*).
  - Таймер обратного отсчета до события (например: *«Осталось 14 дней»*).
  - Индикатор для владельца: плашка *«Подарков в вишлисте: 8 · Забронировано: 3»* (без указания, каких именно!).
- **Панель категорий (Быстрые фильтры):**
  - Горизонтальный скролл с pill-кнопками: *Все*, *Гаджеты*, *Одежда*, *Для дома*, *Книги*, *Другое*.
- **Сетка карточек (Bento-стиль):**
  - Превью-фотография подарка.
  - Название товара, форматированная цена (например: `14 990 ₽`).
  - Бейдж приоритета (*«Мечта ✨»* или *«Очень хочу 🔥»*).
  - **Для дорогого подарка со складчиной:** полоса прогресса (Progress Bar) с суммой (например: `6 000 из 15 000 ₽ собрано`).
  - **Кнопка действия:**
    - Если смотрит создатель: кнопка редактирования/удаления.
    - Если смотрит гость: 
      - Для обычного товара: кнопка **«Подарю я 🎁»** (меняет статус на «Забронирован»).
      - Для товара со складчиной: кнопка **«Скинуться 🤝»** (открывает модалку ввода суммы и показывает контакты соучастников).
- **Плавающая нижняя панель (Sticky Action Bar):**
  - Для владельца: кнопка **«+ Добавить подарок»** и кнопка **«Поделиться вишлистом»** (через нативный `Telegram.WebApp.openTelegramLink`).

### Экран 2: Модалка добавления подарка (для владельца)
- **Поле ввода ссылки:**
  - Вставляется ссылка (WB, Ozon, маркетплейсы, интернет-магазины).
  - Кнопка *«Найти»* / авто-детект: на бэкенд летит запрос, парсер достает заголовок, картинку и цену.
  - Поля автоматически предзаполняются.
- **Ручные поля (если ссылки нет или нужно подправить):**
  - Загрузка / ссылка на фото.
  - Название подарка.
  - Примерная цена в рублях.
  - Выбор категории.
  - Чекбокс: **«Разрешить скинуться (дорогой подарок)»**.

### Экран 3: Модалка «Скинуться на подарок» (для друзей)
- Показывает текущий прогресс сбора: `7 500 из 20 000 ₽`.
- Поле ввода суммы взноса (например: `2 500 ₽`).
- Предупреждение: *«Приложение не принимает платежи. Нажимая кнопку, вы подтверждаете готовность внести сумму, и ваш @username будет виден другим участникам сбора для координации перевода»*.
- Список уже скинувшихся друзей (с аватарами и юзернеймами для перехода в чат).

## 6. Логика Telegram-бота (Уведомления)

1. **При бронировании подарка:**
   - **Создателю вишлиста:**
     > *«Ура! Кто-то из друзей только что забронировал подарок из твоего вишлиста! 🎁 Какой именно — останется тайной до твоего праздника!»*
   - **Дарителю:**
     > *«Ты забронировал подарок: **Название** за **Цена ₽**. Ссылка на покупку: [Перейти в магазин]. Не забудь подготовить его к **Дата события**!»*
2. **При участии в складчине:**
   - **Участникам сбора:**
     > *«@friend присоединился к сбору на **Название** с долей **Сумма ₽**! Вы можете списаться в Telegram для перевода средств.»*
